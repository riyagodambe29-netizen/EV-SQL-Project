# EV-SQL-Project
# Electric Vehicle Charging Analytics using SQL

## Project Overview

This project demonstrates SQL skills by designing and analyzing an Electric Vehicle (EV) database.

## Database Tables

- Customers
- Vehicles
- Charging Stations
- Payments

## SQL Concepts Used

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- INNER JOIN
- COUNT()
- SUM()
- AVG()
- MIN()
- MAX()
- HAVING
- RANK()

## Sample Analysis

- Total vehicles by brand
- Gold members and their vehicles
- Average battery capacity
- Revenue by payment method
- Total payment amount
- Battery capacity analysis
- Vehicle ranking by battery capacity

## Tools

- MySQL
